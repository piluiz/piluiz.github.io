Building a 2-way superscalar out-of-order RISC-V core

An eight-week capstone for UIUC's ECE 411: an RV32IM processor with register renaming, speculation, and a split load-store queue.

The goal of this project was to design a high-performance out-of-order processor that maximizes instruction-level parallelism while maintaining correct program semantics. The core implements the full RV32IM instruction set, including multiply and divide.

Architecture

We used explicit register renaming with a reorder buffer (ROB) to track in-flight instructions. Reservation stations let instructions wait for operands without holding up the rest of the pipeline.

Advanced features

FeatureWhat it does
2-way superscalarFetch, decode, dispatch, and retire up to two instructions per cycle.
Gshare predictorGlobal history combined with the branch address to index the predictor.
Split LSQLoads and stores schedule independently while preserving memory ordering.
Next-line prefetchFetches the next instruction cache line ahead of time.
Takeaway: not every advanced feature works well with the others. Some combinations gave diminishing returns or created new bottlenecks.
